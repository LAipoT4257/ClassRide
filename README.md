# ClassRide — Carpool Planner

**ClassRide** is a student carpool platform designed to help students share rides and travel together. It allows users to create trips, discover available rides, and join trips with fellow students.

The application provides a simple and convenient way to organize shared journeys, manage available seats, and make traveling easier and more accessible for students.

## Features

- **User Registration** – Create a personal ClassRide account.
- **User Login** – Securely access your account.
- **Available Trips** – Browse trips created by other students.
- **Create a Trip** – Publish a trip by providing the starting location, destination, departure date, time, and available seats.
- **Join a Trip** – Join available trips and reserve a seat.
- **Seat Management** – Automatically update the available seat count when students join or leave a trip.
- **My Trips** – View and manage trips you created or joined.
- **Cancel or Leave Trips** – Cancel your own trip or leave a trip you joined.
- **User Profile** – View your account information.
- **Logout** – Safely log out of your account.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.
- **Progressive Web App (PWA)** – Supports installation on compatible desktop and mobile devices.

## How to Install

### Option 1: Install from the Website

1. Open the ClassRide website using a supported browser.
2. Visit the application website:   https://classride.netlify.app
3. On desktop, look for the install icon in the browser's address bar or browser menu.
4. On mobile, open the browser menu and select **Install App** or **Add to Home Screen**, depending on browser support.
5. Follow the installation instructions.
6. Open ClassRide from your device's home screen or application launcher.

### Option 2: Download the Source Code

1. Visit the ClassRide GitHub repository:

   https://github.com/LAipoT4257/ClassRide

2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted project folder using a code editor such as Visual Studio Code.

## How to Run the App

### Using the installed App

1. Find the installed app in your device.
2. Open the app.
3. Register a new account or log in using your existing account.
4. Enjoy the app.

### Using the Live Website

1. Open your web browser.
2. Visit the ClassRide website or the app:

   https://laipot4257.github.io/ClassRide/
   https://classride.netlify.app/

3. Register a new account or log in using your existing account.
4. Start creating and joining trips.

### Running Locally

1. Download and extract the project source code.
2. Open the project folder in Visual Studio Code.
3. Make sure the project files and folders are properly arranged.
4. Open the project using a local development server, such as the **Live Server** extension in Visual Studio Code.
5. Click **Go Live** to launch the application in your browser.
6. Register or log in to start using ClassRide.
